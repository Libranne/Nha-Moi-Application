Nha Moi 09/2024 - 12/2024

  An app for posting, managing, viewing, and searching rental
  listings, helping tenants and landlords find and rent boarding
  houses easily.
  
Team size : 3 members

Responsibilities :

 -  Team leader, Created and designed report documents and
  delivered presentations.
  
-  Developed ideas and plans for UI design and implementation.
  
-  Implemented code for user registration and authentication
  functionality using Firebase Authentication, as well as CRUD
  operations for favorite lists and post search functionality.
  
-  Collaborated with and guided team members in project
  implementation and orientation.

Technologies : Android(Java), XML, Firebase realtime database,
Firebase Authentication, Geolocation, Google Maps API


**Key Features:**  

1. **User Authentication:**  
   - Secure user registration and login using Firebase Authentication.  
   - Support for both tenant and landlord roles.  

2. **Rental Listing Management:**  
   - Landlords can create, update, and delete rental posts with detailed information (price, location, amenities).  
   - Tenants can browse, search, and view listings.  

3. **Favorite Listings:**  
   - Tenants can save their favorite rental listings for quick access.  
   - CRUD operations for managing favorite lists.  

4. **Advanced Search and Filtering:**  
   - Search by location, price range, room size, and amenities.  
   - Filter results based on tenant preferences.  

5. **Interactive Maps:**  
   - Integration with Google Maps API to visualize property locations.  
   - Geolocation feature to find nearby rental listings.  

6. **Real-Time Updates:**  
   - Firebase Realtime Database for instant listing updates without page reloads.  

7. **User-Friendly Interface:**  
   - Responsive and visually appealing UI for smooth navigation.
